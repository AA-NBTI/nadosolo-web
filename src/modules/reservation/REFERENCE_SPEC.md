# 범용 예약 모듈 공식 검증 레퍼런스 규격 (REFERENCE_SPEC)

본 문서는 `src/modules/reservation` 모듈이 상용 수준의 범용 예약 솔루션으로 완성되었는지 검증하는 영구 기준표입니다.

- **엔진 · DB 아키텍처 기준**: [Cal.com](https://cal.com) (`Resource / EventType(Unit) / Schedule / DateOverride / Availability / Booking / Attendee`)
- **매장 운영 · 예약 UX 기준**: [네이버 스마트플레이스 예약](https://new.smartplace.naver.com)

---

## 12대 합격 검증 기준표

| # | 검증 영역 | 필수 기준 | 합격 조건 (Pass Criteria) |
| :-: | :--- | :--- | :--- |
| **1** | **업체 마스터** | 도로명 주소, 상세 위치, 매장 전화, 담당자 휴대폰, 타임존, 이용 안내, 대표 이미지 | 등록·수정 시 모두 저장되고, 회원 확정 화면에 실제 주소·안내 노출 |
| **2** | **예약 상품/유닛** | 한 업체 아래 여러 예약 단위(예: 6인 룸, 4인 홀석) + 최소·최대 인원 + 이용 시간(분) | 1개 업체에 2개 이상 유닛 등록 및 유닛별 정원·시간 독립 적용 |
| **3** | **주간 영업 스케줄** | 요일별(`0~6`) 영업 시작·종료, 브레이크타임, 슬롯 간격(분) | 주간 규칙 1회 저장으로 매주 반복 가용 시간 자동 산출 |
| **4** | **예외일 · 휴무 차단** | 특정 날짜(`YYYY-MM-DD`) 휴무 지정 또는 단축 영업 | 휴무일 지정 시 해당 날짜 조회 시 빈 시간 0개 반환 |
| **5** | **동적 빈 시간 조회** | `(주간 스케줄 - 예외일 - 브레이크 - 겹치는 기존 예약)` 실시간 계산 | 날짜·인원 조회 시 예약 가능 시간대와 잔여 수량 정확 반환 |
| **6** | **동시성 정원 보호** | DB Lock/Trigger 초과 예약 방지, 멱등 키, 홀드 만료 | 동시 요청 시 정원 초과 0건 |
| **7** | **상태 머신 · 정책** | `REQUESTED → CONFIRMED → COMPLETED` + 거절/취소/만료/노쇼 + 폴백 | 잘못된 전이 차단, 48시간 취소 페널티, 거절 시 폴백 |
| **8** | **예약자 · 요청사항** | 예약자명, 연락처, 인원, 특이사항(알레르기·요청) | 예약 생성 시 저장되어 업체 관리 화면에 노출 |
| **9** | **무로그인 즉시 응답** | 서명 토큰 기반 `/r/[token]` 수락·거절 | 만료·변조 차단 및 1클릭 처리 |
| **10** | **업체 전용 관리 화면** | 업체 포털 내 예약 처리 + 매장 정보·영업시간·휴무일 직접 관리 | 업체 로그인 후 예약 응답 및 매장/스케줄 설정 가능 |
| **11** | **양방향 알림** | 예약 요청/확정/취소 이벤트 기반 알림 어댑터 | 알림 발송 인터페이스 및 상태 이벤트 연결 |
| **12** | **이용자 예약 위젯** | 달력 날짜 → 가능 시간 → 유닛 → 인원 → 예약자 정보 입력 직접 예약 UI | 일반 직접 예약 플로우 동작 |
